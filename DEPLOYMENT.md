# Deployment Guide — dalesackrider.com

This document details the architecture, local testing, build steps, and deployment procedures for **Dale Sackrider's personal blog** at [dalesackrider.com](https://dalesackrider.com).

---

## 🏗️ Architecture Overview

- **Framework:** [Astro 5.4](https://astro.build) (Static Site Generation with Cloudflare adapter)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com) + CSS Custom Properties for theme tokens
- **Hosting:** [Cloudflare Pages](https://pages.cloudflare.com)
- **CI/CD:** GitHub Actions (`.github/workflows/deploy.yml`)
- **Content:** Markdown (`src/content/blog/*.md`) with Astro Content Collections schema

---

## 💻 Local Development & Testing

### 1. Install Dependencies
```bash
npm ci
```

### 2. Start Dev Server
```bash
npm run dev
```
Open [http://localhost:4321](http://localhost:4321) (or your designated port) to preview the site locally.

### 3. Build & Typecheck
```bash
npm run build
```
This validates all frontmatter schemas, compiles Markdown, bundles Tailwind styles, and outputs the static site into `dist/`.

### 4. Preview Build Locally
```bash
npm run preview
```
Runs a local Cloudflare worker preview using Wrangler against the built `dist` directory.

## 🚀 Deployment Options

### Option A: Automated Git Deploy (Recommended)
Every commit pushed to the `main` branch automatically triggers the GitHub Actions workflow:
1. Pushes to `main`.
2. GitHub Action sets up Node.js 20.
3. Runs `npm ci` and `npm run build`.
4. Deploys the `dist/` directory to Cloudflare Pages project `dalesackrider-com`.

#### Required GitHub Secrets
Under **Settings > Secrets and variables > Actions**, ensure the following secrets are configured:
- `CLOUDFLARE_API_TOKEN`: Cloudflare API Token with Pages Edit permissions.
- `CLOUDFLARE_ACCOUNT_ID`: Cloudflare Account ID.

---

### Option B: Manual CLI Deploy
Deploy directly from your terminal using Wrangler:
```bash
npm run build
npx wrangler pages deploy dist --project-name=dalesackrider-com
```
Or use the direct npm script:
```bash
npm run deploy
```

## 📝 Publishing Content Checklist

1. Create a new markdown file in `src/content/blog/<slug>.md`.
2. Populate frontmatter:
   ```yaml
   ---
   title: "Your Title Here"
   description: "Concise summary under 160 characters."
   pubDate: "YYYY-MM-DD"
   tags: ["leadership", "cloud", "systems"]
   draft: false
   ---
   ```
3. Test locally with `npm run build`.
4. Commit and push to GitHub:
   ```bash
   git add .
   git commit -m "Publish: <Title of Post>"
   git push origin main
   ```

## 🔧 Troubleshooting

| Issue | Resolution |
| :--- | :--- |
| **Node.js version mismatch** | Ensure Node 18+ or 20+ is selected in Cloudflare Pages build settings or environment variables (`NODE_VERSION=20`). |
| **Route 404s on refresh** | Ensure `dist/` contains valid `index.html` files generated by `astro build` (standard for static generation). |
| **Schema validation error** | Check `src/content/blog/` files for missing required frontmatter fields (`title`, `description`, `pubDate`). |
| **Styles not updating** | Ensure Tailwind v4 `@import "tailwindcss";` is imported in `src/styles/global.css`. |
| **Dark mode flicker (FOUC)** | `BaseLayout.astro` includes an inline script in `<head>` that reads `localStorage` before paint. |
