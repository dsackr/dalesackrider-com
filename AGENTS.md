# Dale Sackrider Blog — Agent Guidelines

This repository hosts the source code and Markdown content for **Dale Sackrider's personal blog** at [dalesackrider.com](https://dalesackrider.com).

## Key Workflows
* **Write/Edit Content:** `src/content/blog/<slug>.md`
* **Local Build:** `npm run build`
* **Local Preview:** `npm run dev`
* **Deploy to Cloudflare:** `npx wrangler deploy`
* **Push to GitHub:** `git push origin main`

## Editorial Guidelines
Always follow the **`dalesackrider-blog`** skill instructions for voice, tone, structure, frontmatter schemas, and publishing checklists.
